# You've Been Served / Mercy Run

A satirical, nonviolent rescue arcade prototype from Urantia Book Network. Play as Jesus, dash through a Jerusalem-inspired market, save 18 neighbors and break Caligastia's influence with Gray Rock and No Contact. The boss mechanics and comic dialogue are fictional.

**GitHub Pages:** [Play You've Been Served](https://ubn606.github.io/youve-been-served/).

Six hits exhaust your composure. Dash through danger, and intercept boss projectiles with Gray Rock. Four successful counters charge No Contact.

Use a recent browser with hardware acceleration. Tap or click Start to begin and unlock sound. No account or paid generation runs during play. Your personal best stays in this browser's local storage.

| Action | Keyboard / mouse | Standard controller |
| --- | --- | --- |
| Move | WASD / arrows | Left stick |
| Look | Right-mouse drag | Right stick |
| Serve | Hold Space / E / left click | Hold A / RT |
| Dash | Shift | B |
| Gray Rock / charged city rescue | Q | Y |
| No Contact when charged | R | X |
| Pause / resume | P / Escape | Start |
| Begin / restart | On-screen button | A / Start |

On a phone, use the left movement stick, drag the scene to look, and use the named action buttons. Landscape is recommended. Sound and quality controls are at the top. Physical phone and controller compatibility still need testing.

This is a prototype: character motion, crowd variety, art fidelity and voice performances remain works in progress. The city is inspired by the setting, not an archaeological reconstruction. Optional reading cards link to [Rebellion Tested](https://www.urantiabooknetwork.com/rebellion) and [The Urantia Book, Paper 173](https://multilanguagebook.urantia.org/Est/Eng/papers/173); these sources are separate from the fictional game mechanics.

The offline ZIP includes its own launch instructions and requires Node.js 18 or newer. This repository contains only the static playable package. See [CREDITS.md](CREDITS.md) and [LICENSE.md](LICENSE.md) for component notices and licensing limits.
